# 물병 4개형 바구니 — 2차 설계 (외부 돌출 없는 고리)

지름 85mm, 뚜껑 포함 길이 215mm인 물병을 눕혀 가로 2개 × 높이 2단으로 담는 초기 모델입니다. 물병 치수는 대화에서 도출한 가정이며 실물의 가장 큰 치수로 확인해야 합니다. 중간 선반은 없습니다.

## 치수 (mm)

| 항목 | 치수 |
|---|---|
| 내부 가로 × 앞뒤 × 높이 | 175 × 220 × 175 |
| 몸통 외부 가로 × 앞뒤 × 높이 | 185 × 230 × 180 |
| 고리 포함 전체 가로 × 앞뒤 × 높이 | 185 × 230 × 202 |
| 벽 / 바닥 | 5 / 5 |
| 상단 고리 | 4개, 구멍 지름 8, 두께 10 |
| 고리 상단 외곽 반지름 | 11 |
| 모서리 라운딩 | 최대 1 |

가로와 높이는 물병 85mm 두 개의 합계에 총 5mm 여유를 둡니다. 앞뒤 길이도 병 215mm에 총 5mm 여유를 둡니다. 고리의 바깥면은 앞뒤 벽 바깥면과 같은 평면이며 가로·앞뒤 외곽을 넘어 돌출되지 않습니다. 고리 뿌리는 벽과 같은 5mm 두께이고, 몸통 위에서 안쪽으로 경사지게 두꺼워져 구멍 부분에서 10mm가 됩니다. 몸통 높이 이하의 내부 수납 치수는 유지합니다. 벽 모서리 라운딩은 그대로입니다.

바구니 3개를 가로로 밀착 배치하면 전체 외곽은 555 × 230 × 202mm입니다. 이는 각각 출력한 바구니의 배치 예시이며 체결 부품이나 끈의 두께는 포함하지 않습니다. 연결 부품 설계 및 하중 시험은 별도입니다.

## 파일

- `basket_4b_v2.blend`: 수정된 편집용 블렌더 파일. 출력 본체는 `Basket_4_bottles_PRINT`입니다. 물병 크기 확인용 원통 4개는 숨겨진 참고 컬렉션에 있으며, 바닥·조명·카메라는 미리보기용입니다.
- `basket_4b_v2_mm.stl`: 수정된 바구니 본체만 포함하는 mm 단위 출력용 메시입니다.
- `basket_4b_v2_preview.png`: 수정 모델 미리보기.
- `basket_4b_v2_three_preview.png`: 3개를 밀착 배치한 미리보기.
- `build_basket.py`: 치수 상수를 수정해 모델을 재생성할 수 있는 블렌더 스크립트.
- `validation_v2.json`: 수정 모델 메시 검사, 외부 돌출 검사 및 물병 기준 원통과의 겹침 검사 결과.

기존 v1 파일은 이전 형태를 비교할 수 있도록 보존했습니다. 현재 수정본은 v2입니다.

## 확인 범위와 다음 단계

메시는 하나로 연결된 닫힌 입체인지, 면 방향과 외곽 치수가 정상인지 검사합니다. 고리 포함 외곽 치수는 P1S의 공식 최대 출력 범위 256 × 256 × 256mm 안에 들어갑니다. 실제 Bambu Studio 슬라이싱, 출력 금지 영역·브림·서포트 설정 확인과 실물 하중 시험은 아직 하지 않았습니다. 5mm는 모델의 벽 두께이며 슬라이서의 벽 수·인필 설정과는 별개입니다. 허용 하중은 아직 정하지 않았습니다.

고리는 사용자 요청에 따라 끈 또는 케이블타이용입니다. 구멍 8mm는 실제 끈 지름이나 케이블타이 단면 규격을 확인하기 전의 초기 치수입니다. 바구니 3개를 연결해 물병 12개를 담는 구성은 후속 작업이며 연결 부품은 이번 파일에 포함하지 않았습니다.
