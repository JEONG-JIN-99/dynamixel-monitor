# 현재 모터 체결부 구멍 지름 비교 테스트

[experiment_plate_mount_test_D2p5_D2p6_D2p7.stl](experiment_plate_mount_test_D2p5_D2p6_D2p7.stl)

마찰판 `../experiment_plate_friction.stl`에서 실제 모터 받침 윗부분20mm를 추출한 뒤 구멍 지름을 각각2.5/2.6/2.7mm로 만든 시험편3개입니다. 하나의 STL 안에 서로 떨어진 부품3개를 넣었습니다. 윗면의 D2.5 / D2.6 / D2.7 음각으로 구분합니다.

- 각 시험편 크기44 × 36 × 20mm. 부품 간격10mm, 전체배치152 × 36 × 20mm.
- 각 시험편 나사 구멍4개: Ø2.5 / Ø2.6 / Ø2.7mm, 모두 깊이15mm. 바닥 잔여 두께5mm.
- 구멍 중심간격24 × 12mm. FR12-S102K 바깥쪽4개 탭과 대응.
- FHS M2.5×14를 프레임에서 시험편 방향으로 조이는 시험용. 모델에 암나사산은 없습니다.
- 구멍이 위로 향하도록 mm 단위, 배율100%로 출력합니다. 전체판과 같은 재료 및 구멍 주변 출력 설정을 사용하면 비교에 도움이 됩니다.

STL 재가져오기로 폐쇄 입체3개, 치수, 구멍12개의 위치·지름·깊이, 부품 간격과 음각을 검사했습니다. 시험편은 나사 체결 확인용이며 전체 판의 높이, 강도, 모터/릴 간섭을 검증하는 부품은 아닙니다. 원래 마찰판의 구멍Ø2.5mm는 변경하지 않았습니다.

생성: Blender에서 `build_mount_tests.py` 실행. 독립 검증: `verify_mount_tests.py` 실행. 단일Ø2.5mm 이전 시험편은 `../archive/single_mount_test_D2p5_20260922/`에 보관했습니다.
