# 인계 검증 기록

검증일: 2026-09-24. Windows / Python 3.14.5 / Node.js 24 계열.

- 백엔드: 54개 테스트 및 45개 하위 사례 통과.
- 프론트엔드: 49개 단위 테스트 통과. 전달 JSON 예시의 53개 주소와 실제 수신 어댑터 호환성 포함.
- 브라우저: 일반 화면 40개, 제어·로그 3개 통과. 별도 1시간 부하용 브라우저 사례 1개는 기본 실행에서 제외되며, 1시간 원본 이력은 백엔드 테스트에서 검증.
- TypeScript 검사와 배포 빌드 성공.
- 실제 ZIP 생성 → 프로젝트 밖 임시 폴더 추출 → 폴더 이름을 공백 포함 이름으로 변경 → 다른 작업 디렉터리에서 main.py 실행 검증.
- 독립 전달본에서 초기 대기, 설정 저장, 가상 실험 시작, 53개 주소 실시간 수신, CSV와 실시간 값 일치, 왕복 종료, 로그 조회, 서버 재시작 후 기록 복원 검증.
- 기존 실험 기록·가상환경·node_modules가 전달 ZIP에 포함되지 않는지 확인.

이 검증은 장치 없는 프로토타입 및 통신 계약 검증입니다. 실제 모터/협업자의 수집 코드/고장 판정 정확도는 검증하지 않았습니다. 독립 전달본 실행은 프로젝트 코드를 참조하지 않도록 분리했으며, Python 의존성은 검증 환경에 설치된 라이브러리를 사용했습니다. 새 컴퓨터에서의 최초 pip 설치 자체를 재현한 검증은 아닙니다.

알려진 비차단 경고: 큰 프론트엔드 번들에 대한 Vite 경고, 테스트 라이브러리의 사용 중단 예고, Windows 브라우저 연결 종료 시 asyncio connection reset 로그. 위 기능 테스트는 통과했습니다.
