# 모터 페이지: XM430 일반 주소 53개

공식 문서 확인: 2026-09-23

- https://emanual.robotis.com/docs/en/dxl/x/xm430-w210/#control-table
- https://emanual.robotis.com/docs/en/dxl/x/xm430-w350/#control-table

EEPROM 22개와 일반 RAM 31개를 표시한다. 간접 주소·간접 데이터 및 예약 주소는 제외한다. 다른 모델의 테이블로 잘못 해석하지 않도록 W210/W350만 지원한다.

`services/controlTable.ts`가 주소·크기·접근 권한·한국어/공식 명칭과 변환을 정의한다. `views/MotorsView.vue`는 모델/ID 선택, 전체·영역 필터, 검색, 정렬, 행별 설명, 표시 일시정지를 제공한다. 일시정지는 화면만 멈추며 수집 및 store 갱신은 계속된다. 모델/소스/실험 전환 시 정지 상태를 해제한다.

## 현재 CSV와의 연결

현재 측정 샘플과 시작 메타데이터에서 제공되는 값만 연결한다. 통신 설정 JSON이나 공식 초기값을 실제 주소 읽기 결과로 사용하지 않는다. 변환된 PWM/전류/속도/전압만 수신되면 원시값은 —, 수신 상태는 ‘변환값 수신’이다. 목표 위치 명령은 ‘명령 기록’으로 구분한다. 최신 샘플이 없으면 0으로 채우지 않는다.

**이번 작업은 프론트엔드 구현이다. 실험 코드/백엔드의 실제 53개 주소 수집을 추가하지 않았다.** 가상 데이터에서는 명확히 표시한 시연 fixture로 53개 전부 확인할 수 있다.

## 확장 입력 계약

실제 수집기가 확장될 때 기존 `Sample` 또는 해당 모터의 `MotorMetadata`에 선택적 `registers` 필드를 보낼 수 있다. 기본 소켓 Message 계약은 유지한다.

```json
{
  "registers": {
    "126": { "raw": 161, "receivedAt": 1790125200000, "status": "received" },
    "147": { "raw": null, "receivedAt": 1790125200000, "status": "unsupported" }
  }
}
```

키는 십진수 시작 주소. raw는 주소의 정수값(부호 있는 값 또는 미해석 unsigned 정수), receivedAt은 수집 시각 Unix ms, status는 received/unsupported/error. error에 오류 설명을 넣을 수 있다. 샘플과 메타데이터에 같은 주소가 있으면 receivedAt이 더 최신인 읽기 결과를 사용한다. 최신 오류를 오래된 정상값으로 가리지 않는다. 모터별 모델과 ID가 맞는 객체에만 넣어야 한다.

백엔드가 모든 53개 값을 보내면 같은 표에 표시된다. 현재 백엔드는 이 필드를 보내지 않으므로 일부 칸은 미수신이 정상이다. EEPROM은 시작/설정 변경 후 읽고, 측정 RAM은 반복 수집하는 방식으로 별도 주기를 둘 수 있다. 헤더의 데이터 수집 주기는 현재 실험 샘플 주기이며 모든 EEPROM 주소가 그 주기로 읽힌다는 뜻은 아니다.

부호 해석·전류/속도/전압 단위 변환과 시간 기반 프로파일 분기를 지원한다. 프로파일 변환은 드라이브 모드(10)가 수신되어야 적용한다. Startup Configuration(60)과 Backup Ready(147)는 V45 이상 조건을 표시한다. R/RW는 모터 주소의 권한이며 이 화면은 모터에 쓰기 명령을 보내지 않는다.
